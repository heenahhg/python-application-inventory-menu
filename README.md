# Python Application Inventory Management System

A Python-based console application for managing an application inventory.

The project was created as part of my Python learning journey and demonstrates practical use of Python fundamentals, functions, lists, dictionaries, loops, conditional statements, input validation, exception handling, JSON file handling, and Git/GitHub version control.

## Features

- Display all applications in the inventory
- Search applications by name
- Add a new application
- Prevent duplicate applications
- Delete an application
- Update application details
- Handle multiple matching applications
- Validate application version format
- Validate required fields
- Save inventory data to a JSON file
- Load inventory data when the application starts
- Preserve changes between program sessions
- Handle missing JSON file using default application data
